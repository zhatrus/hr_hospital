🚗 Fleet Monitoring System

Система моніторингу автопарку для Odoo 17 з підключенням до зовнішньої PostgreSQL бази даних GPS-трекерів та паливних карток.

📊 Дашборд

Статистика по транспортних засобах, пробігу, паливу та порушенням швидкості в реальному часі.

🗺️ Моніторинг

Відстеження позицій всіх ТЗ з відображенням статусу (в русі / на стоянці / офлайн).

🛣️ Поїздки

Автоматичний розрахунок поїздок на основі GPS-даних з пробігом, часом та максимальною швидкістю.

⛽ Паливо

Облік заправок з паливних карток, аналітика витрати та порівняння з нормою.

Можливості

  • Підключення до зовнішньої PostgreSQL бази даних
  • Синхронізація транспортних засобів
  • Відображення останньої позиції з GPS-трекерів
  • Журнал поїздок з автоматичним розрахунком
  • Аналітика витрати палива по ТЗ
  • Виявлення порушень швидкості
  • Pivot та Graph звіти
  • Налаштування ліміту швидкості

Зовнішня база даних

Модуль працює з такими таблицями зовнішньої PostgreSQL БД:

  • vehicles — транспортні засоби (IMEI, держ.номер, модель, паливна картка)
  • tracker_light — GPS дані (координати, швидкість, паливо, одометр)
  • fuel_transactions — транзакції з паливних карток

Налаштування підключення

Параметри підключення можна задати двома способами:

1. Через інтерфейс Odoo

Налаштування → Fleet Monitor → Підключення до БД

2. Через конфігураційний файл odoo.conf

[options]
auto_monitoring_db_host = 192.168.1.100
auto_monitoring_db_port = 5432
auto_monitoring_db_name = monitoring
auto_monitoring_db_user = lynx
auto_monitoring_db_password = your_password

Технічні вимоги

Odoo 17.0 Python 3.10+ psycopg2 PostgreSQL

Встановлення

  1. Скопіюйте модуль auto_monitoring в папку addons
  2. Встановіть залежність: pip install psycopg2-binary
  3. Оновіть список модулів в Odoo
  4. Встановіть модуль "Fleet Monitoring System"
  5. Налаштуйте підключення до зовнішньої БД
  6. Натисніть "Синхронізувати ТЗ" для імпорту транспортних засобів

Групи доступу

  • User — перегляд даних
  • Manager — керування ТЗ та звіти
  • Administrator — повний доступ включно з налаштуванням БД
