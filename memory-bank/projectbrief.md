# Project Brief

## Основна мета
**auto_monitoring** - модуль Odoo 17 для моніторингу автопарку з підключенням до зовнішньої PostgreSQL БД.

## Ключові вимоги
- [ ] Підключення до зовнішньої БД (tracker_light, fuel_transactions, vehicles)
- [ ] Дашборд зі статистикою (ТЗ, пробіг, паливо, порушення)
- [ ] Моніторинг в реальному часі (список ТЗ, статус, швидкість)
- [ ] Журнал поїздок (маршрути, час, пробіг)
- [ ] Облік палива (заправки, витрата, залишки)
- [ ] Звіти (пробіг, паливо, порушення)
- [ ] Налаштування ТЗ та сповіщень

## Обмеження
- Odoo 17.0
- Зовнішня PostgreSQL БД (read-only)

## Цілі
- Відображення даних з GPS-трекерів у зручному інтерфейсі Odoo
- Аналітика витрат палива та пробігу
